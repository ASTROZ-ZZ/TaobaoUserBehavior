# 指标字典

| 指标 | 分子/分母与统计单位 | 时间与边界 |
| --- | --- | --- |
| PV | pv事件数 | 清洗窗口；保留精确重复 |
| UV/DAU | 期间/当日任意行为去重用户 | UV不跨日累加 |
| 浏览UV/人均浏览 | 有pv用户数；PV÷浏览UV | 指定期间 |
| 购买用户占比 | 有buy用户数÷任意行为UV | 非顺序转化 |
| 24小时转化 | 行为起点后同用户同商品购买对数÷完整随访起点对数 | 起点取窗口首次该类行为；严格晚于起点且≤24小时；起点+窗口<观察期结束 |
| 分支漏斗 | 浏览起点→首次后续收藏/加购→严格后续购买 | 全链在浏览后24小时内；路径可重叠 |
| 小时购买占比 | 该小时购买用户—小时数÷活跃用户—小时数 | 跨日按总分子总分母合并 |
| 起点小时转化 | 按浏览起点小时分组的24小时转化 | 不是购买发生小时 |
| Dn留存 | Cohort第n天活跃人数÷起始人数 | D0为窗口首次活跃日；右侧不可观察留空 |
| 再次购买 | 首次观察购买日之后其他日有buy | 固定3天随访比较仅保留完整Cohort |
| 购买间隔 | 同用户相邻购买日各日首次buy时间差 | 以全部可观察间隔汇总，不是订单间隔或长期周期 |
| 高活跃 | 活跃天数≥全体中位数 | 以quality.json实际阈值为准 |
| 高购买/高频购买 | 购买天数≥2 / ≥3 | 全窗口描述，不含金额 |
| 商品转化排名 | 24小时浏览起点转化率 | 主门槛100对，另比较50/200对 |
| 商品象限 | 合格商品浏览UV的P75与转化率中位数 | 低于100起点对的商品不强行评级 |

历史分群使用起点前自然日，排除起点当天所有行为；起点当天不完整历史不作补全。同秒多行为不确立严格顺序。工作日/周末规模比较使用日均值，率使用分子/分母加权。
