# 数据字典

处理明细在 `data/processed/`，分析结果在 `results/`；原始CSV保留在 `data/raw/`。本次改用已有 pandas + NumPy 分批处理，SQLite合并商品聚合，未依赖DuckDB。

| 文件 | 粒度与主要字段 |
| --- | --- |
| data/processed/events_clean.csv.gz | 保留的事件行：user_id/item_id/category_id/behavior_type/timestamp/day/hour；day=0对应11月25日；重复行保留 |
| data/processed/user_day.csv.gz | 用户×自然日：四种行为次数；有行为的日期才有行 |
| data/processed/users.csv.gz | 每用户一行：四行为次数、活跃天数、购买天数、窗口首次/末次日期偏移、品类数、购买商品数、分层与意向画像 |
| data/processed/item_day.csv.gz | 商品×自然日四行为次数 |
| data/processed/item_id_metrics.csv.gz | 每商品一行：次数、去重用户、24小时浏览起点转化 |
| data/processed/category_id_metrics.csv.gz | 每品类一行：事件规模、去重用户；转化分母为该品类的用户—商品对 |
| data/processed/repeat_intervals.csv.gz | 用户×可观察相邻购买日间隔，单位小时 |
| data/processed/analysis.sqlite | users及报告摘要表；不包含全量事件。core_queries.sql可直接执行 |
| 02–06各阶段CSV | 面向图表的汇总结果；源指标名保留英文以便复现 |

ID是匿名标识符，不代表连续数量；时间戳是Unix秒。按北京时间派生day/hour。CSV.GZ是标准gzip压缩CSV，可使用pandas分批读取。品类名称不可还原。
