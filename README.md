# Taobao User Behavior Analysis

淘宝用户行为与商品运营分析项目。使用天池公开的淘宝用户行为日志，完成数据清洗、行为转化分析、用户分层、时间特征与商品机会识别。

## 项目内容

- `Scripts/`：数据处理、分析、绘图和结果核验代码。
- `docs/`：任务、数据字段和指标口径说明。
- `reports/`：综合分析报告、综合看板和作品集。
- `results/`：分主题分析表、图表和运营清单。
- `PowerBI/`：Power BI 项目文件。

原始数据与大型中间文件不纳入 GitHub。可按 `data/README.md` 中说明获取数据并运行分析。分析基于2017年11月25日至12月3日的观察窗口，结论受日志字段和观察范围限制。

## AI 协助说明

本项目的部分代码整理、报告整合和看板内容曾使用 AI 辅助。项目使用者应核对分析口径、结果和代码，并对最终提交内容负责。
