# 数据分析与绘图代码导航

所有命令在 `UserBehavior/` 目录执行。原始输入为 `data/raw/UserBehavior.csv`，处理结果写入 `data/processed/`，分析表与图表写入 `results/`。

| 类别 | 脚本 | 作用 |
| --- | --- | --- |
| 全量流程 | `run_pipeline.py` | 依次运行数据处理、用户分析、质量复核、业务分析绘图、运营清单与结果核验 |
| 数据处理与主体分析 | `01_analyze.py` | 分块清洗日志，计算转化、平台、用户和商品指标 |
| 用户分析 | `02_segment_preferences.py` | 计算用户分层的品类偏好与高频画像 |
| 结果核验 | `04_verify.py` | 从已处理数据独立核对主要统计结果 |
| 数据质量审计 | `06_quality_audit.py` | 独立扫描原始文件并复核数据质量 |
| 样本门槛分析 | `07_export_low_sample.py` | 导出样本量不足以进入转化排名的商品与品类 |
| 业务分析与绘图 | `13_recruiter_business_analysis.py` | 汇总用户贡献、购买频次、商品资源效率并绘制分析图 |
| 运营对象分析 | `14_export_operating_lists.py` | 生成重点人群与商品运营清单 |
| SQL查询 | `core_queries.sql` | 查询SQLite摘要数据 |

## 常用运行方式

- 全量数据处理、分析、绘图与核验：`python Scripts/run_pipeline.py`。
- 只更新业务分析与图表：`python Scripts/13_recruiter_business_analysis.py`，需已有 `data/processed/` 和前序分析结果。
- SQL查询：`sqlite3 data/processed/analysis.sqlite < Scripts/core_queries.sql`。

依赖版本见 `requirements.txt`。运行会覆盖相应派生结果，原始CSV保持只读。
